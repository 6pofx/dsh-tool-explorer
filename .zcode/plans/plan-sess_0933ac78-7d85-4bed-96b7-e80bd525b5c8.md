回滚 dsh-tool-explorer 一个版本并恢复 dsh 可启动状态（启动验证由用户自行执行）

背景：dsh 实际加载的插件是 profile 目录里的快照拷贝（`C:\Users\fansile\.dsh\profiles\web\node_modules\dsh-tool-explorer`，由 `file:G:/dsh-tool-explorer/dsh-tool-explorer-0.3.0.tgz` 安装），仓库回滚后必须重建、重装这份拷贝，dsh 才会真正回到旧版本。

我执行的步骤：

1. 回滚仓库一个版本
   - `git reset --hard HEAD~1`：从 5fa2182（"fix: skills list shows catalog hidden"）退回 394409f（"ui: rename settings section"）。
   - 工作区干净，无未提交改动会丢失；5fa2182 保留在 reflog，可随时 `git reset --hard 5fa2182` 找回。

2. 重新构建：仓库根目录 `npm run build`（重新生成 lib/ 与 client/client.js）。

3. 重新打包：`npm pack` 覆盖 `dsh-tool-explorer-0.3.0.tgz`（版本号不变，profile 依赖继续指向它）。

4. 重装到 profile 并核对
   - 优先 `dsh plugin --profile web add G:/dsh-tool-explorer/dsh-tool-explorer-0.3.0.tgz`；不可用则退回在 `C:\Users\fansile\.dsh\profiles\web` 执行 `pnpm install`。
   - 核对安装副本 `lib/*.js` 为回滚后的内容（不再是 22:18 那套）。

你执行的部分：启动 `dsh web` 验证是否恢复正常。若启动仍失败，把控制台报错发我——那说明根因不在最后一次提交，我再排查其他嫌疑（stderr monkey-patch、archify 跨层重复 loader 等）。
